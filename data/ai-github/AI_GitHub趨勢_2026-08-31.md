**1.**

- 主題：deepseek-ai/deepseek-harness
- 功能：DeepSeek 開源的 AI Agent 基礎框架，核心理念是「一切皆插件」，包括模型適配器與 Agent 迴圈本身都是可替換的插件。支援約 40 家模型供應商，環境理解、工具使用、會話管理與持續運行等功能開箱即用。TypeScript monorepo，約 50 萬行程式碼，MIT 授權。
