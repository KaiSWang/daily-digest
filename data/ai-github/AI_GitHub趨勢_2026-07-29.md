**1.**

- 主題：MCP 2026-07-28 規格正式進入 Release Candidate
- 功能：Model Context Protocol 發布有史以來最大幅度改版，核心變為無狀態協定（Stateless），移除協定層 Session 與 Mcp-Session-Id header，新增 Extensions 框架、Tasks、MCP Apps、授權強化機制與正式棄用政策。遠端 MCP 伺服器不再需要 sticky session 或共享 session store，可直接部署於一般 round-robin 負載平衡器後方。Python、TypeScript、Go、C# SDK 同步發布 Beta 版。
- 成長幅度：MCP 社群已超過 5,800 個公開伺服器，成為 AI 工具整合的事實標準。
- 可應用領域發想：企業可開始評估將內部工具以 MCP 標準化，降低多模型切換成本；台灣 SaaS 廠商可搶先發布 MCP 伺服器以吸引國際 AI 代理生態流量。

二、GitHub 熱門專案（5 個）

**1.**

- 主題：OpenClaw - 開源個人 AI 助理
- 功能：完全在本地裝置運行的個人 AI 代理，作為本地閘道連接 AI 模型與超過 50 種整合服務（WhatsApp、Telegram、Slack、Discord、Signal、iMessage 等），可全天候自動執行任務。
- 成長幅度：350K+ 星數，5 個月內從 9,000 星暴增至 GitHub 史上最多星數的軟體專案，超越所有既有開源專案。
- 可應用領域發想：台灣開發者可基於 OpenClaw 架構建立本地化的 AI 助理，整合 LINE 等在地通訊平台，打造符合台灣使用習慣的個人代理。

**2.**

- 主題：Strix - AI 滲透測試工具

- 主題：Bumblebee - Perplexity AI 開源供應鏈安全掃描器
- 功能：以 Go 1.25 撰寫的唯讀供應鏈掃描器，檢查開發者機器上的可疑套件。涵蓋 npm、pnpm、Yarn、Bun、PyPI、Go modules、RubyGems、Composer，並能掃描 MCP 設定檔與編輯器/瀏覽器擴充套件。單一靜態二進位檔，無外部相依。Apache 2.0 授權。

- 可應用領域發想：隨著 MCP 生態系擴張，供應鏈攻擊面也在增加。台灣開發團隊應將 Bumblebee 整合至 CI/CD 流程，定期掃描專案相依性與 AI 工具設定。
