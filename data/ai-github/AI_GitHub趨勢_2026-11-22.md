二、GitHub 熱門專案（至少 5 個）

**1.**
- 主題：GoogleChrome/modern-web-guidance-src
- 功能：Google Chrome 官方發布的 AI 程式代理（coding agent）網頁開發指引資源庫，提供系統化的現代 Web 開發最佳實踐，專為 LLM 與 coding agent 優化
- 成長幅度：連續四天位居 GitHub 每日新增星數榜首，單日 +1,220 stars
- 可應用領域發想：台灣前端工程師與 AI 輔助開發工具廠商可將此資源整合進 coding agent 的上下文知識庫，提升代碼生成品質
- 連結：https://www.google.com/url?q=https://github.com/GoogleChrome/modern-web-guidance-src&source=gmail&ust=1795472089957000&sa=E

**2.**
- 主題：ChromeDevTools/chrome-devtools-mcp
- 功能：透過 MCP（Model Context Protocol）讓 coding agent 能直接操作 Chrome DevTools，包括網路監控、JavaScript 除錯、效能分析等，使 AI 助理具備完整的瀏覽器開發者工具控制能力
- 成長幅度：累積約 56,000 stars，仍保持每日活躍增長
- 可應用領域發想：自動化測試、AI 驅動的前端 debug 工作流、無代碼爬蟲與自動化腳本，特別適合整合進 Claude Code、Cursor 等 AI 開發環境
- 連結：https://www.google.com/url?q=https://github.com/ChromeDevTools/chrome-devtools-mcp&source=gmail&ust=1795472089957000&sa=E

**3.**
- 主題：google-labs-code/stitch-skills
- 功能：Google Labs 發布的設計稿轉程式碼（design-to-code）技能集，讓 AI agent 能直接將 Figma/Sketch 設計稿轉換為可執行的前端程式碼，進入 AI 技能模組化的領域特化階段
- 成長幅度：9,093 stars，單日 +248 stars，1,083 forks
- 可應用領域發想：UI/UX 設計師與前端工程師的協作流程可大幅縮短，台灣設計工具新創與 Web Agency 可研究如何將此技能整合進設計到交付的自動化管線
- 連結：https://www.google.com/url?q=https://github.com/google-labs-code/stitch-skills&source=gmail&ust=1795472089957000&sa=E

**4.**

- 功能：阿里巴巴開源的 Go 語言程式碼審查工具，結合 AI 能力自動化程式碼品質審查，支援多種語言與程式碼規範，針對企業級大型程式碼庫優化

- 可應用領域發想：適合台灣軟體公司在 CI/CD 流程中導入自動程式碼審查，特別是規模較大的工程團隊可減少人工 code review 負擔

三、開發者工具與框架趨勢（N 項）

**1.**
- 主題：MCP（Model Context Protocol）成為 AI Agent 整合的事實標準
- 功能：Anthropic 推動的 MCP 已原生整合進 Claude Code、Cursor、Codex CLI、Windsurf 等主流 AI 開發工具，LangGraph、CrewAI、n8n 也推出 MCP adapter；Anthropic 更將 MCP 移交 Linux Foundation 旗下 Agentic AI Foundation 管理，強化開放標準定位
- 成長幅度：已有數千個公開發布的 MCP server，採用廠商持續增加
- 可應用領域發想：台灣開發者可透過撰寫自訂 MCP server 將內部系統（ERP、CRM、資料庫）接入 AI agent，快速賦能企業自動化工作流
- 連結：https://www.google.com/url?q=https://thenewstack.io/ai-engineering-trends-in-2025-agents-mcp-and-vibe-coding/&source=gmail&ust=1795472089957000&sa=E

**2.**
- 主題：Google A2A（Agent-to-Agent）協議與 MCP 形成雙層架構
- 功能：Google 推動的 A2A 協議專注於 AI agent 之間的通訊標準（agent-to-agent），與 MCP 的 agent-to-tool 層形成互補；兩者並用可建構出完整的多 agent 協作系統
- 成長幅度：在企業 AI 架構討論中快速普及，成為 2026 年 AI 系統設計必學概念
- 可應用領域發想：適合台灣想構建企業級多 agent 系統的工程師，可研究 A2A + MCP 雙協議架構，應用於客服自動化、供應鏈智能決策等複雜場景
- 連結：https://www.google.com/url?q=https://dev.to/lui_were/from-chatbots-to-agents-how-agentic-ai-and-mcp-are-changing-software-development-4f83&source=gmail&ust=1795472089957000&sa=E

**3.**
- 主題：NVIDIA OpenShell — Rust 語言驅動的自主 Agent 執行環境
- 功能：NVIDIA 開源的 OpenShell 是以 Rust 語言打造的自主 AI agent 執行環境（runtime），強調高效能、低延遲與安全性，專為需要密集計算的 agent 任務設計
- 成長幅度：10 月 GitHub Trending 活躍出現，每日星數持續增長
- 可應用領域發想：適合台灣 AI 基礎設施廠商與 HPC 工程師研究，特別是有意在邊緣計算或本地部署環境建構 AI agent 的團隊
- 連結：https://www.google.com/url?q=https://startupcorners.com/digest/devtools-digest-2026-10-01&source=gmail&ust=1795472089957000&sa=E
