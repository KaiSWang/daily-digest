二、GitHub 熱門專案（至少 5 個）

**1.**
- 主題：laya（NandhaKishorM/laya）
- 功能：非自回歸 System 1 決策引擎，針對任意文字進行類型化選擇、評分與是否判斷，單次前向傳播即可完成，無需生成文字、PyTorch 或雲端 API，設計目標為極低延遲的決策推論。
- 成長幅度：21,220 顆星，為今日 GitHub 最熱門 AI 專案，吸引力遠超同類。
- 可應用領域發想：適合台灣金融科技公司用於即時信用評分、交易異常偵測，以及電商平台的即時推薦決策，7-14ms 的延遲極具競爭力。
- 連結：https://www.google.com/url?q=https://github.com/NandhaKishorM/laya&source=gmail&ust=1790374326178000&sa=E

**2.**

- 成長幅度：6,598 顆星，今日排名第二，顯示市場對企業級程式設計 Agent 框架的高度關注。
- 可應用領域發想：台灣軟體開發公司可評估用於自動化程式碼審查、Bug 修復與 PR 自動生成，縮短開發周期並降低人力成本。

- 功能：Laya 決策模型的原生 MLX 執行環境，專為 Apple Silicon（M3 Max）優化，決策延遲 7-14ms，無需 PyTorch 或雲端 API，提供可重現的速度與能耗基準測試。
- 成長幅度：6,053 顆星，與 laya 主專案同日登上熱門，反映開發者對在地端 AI 推論的強烈興趣。

四、趨勢觀察（3 則）

**1.**
- 主題：AI 生態從「模型競爭」轉向「基礎設施競爭」
- 分析：今日 GitHub 熱門專案清楚顯示，開發者關注點已從比較哪個模型更強，轉移到如何讓 Agent 在生產環境中穩定、安全、可擴充地運作，記憶管理、Agent 監控、跨廠商協調成為三大核心基礎設施需求，這與 CNBC 報導的「模型疲勞」現象高度一致，投資人應關注基礎設施層而非僅關注模型廠商。
- 連結：https://www.google.com/url?q=https://github.com/yaojiejia/agents-radar/issues/173&source=gmail&ust=1790374326178000&sa=E

**2.**
- 主題：本地端 AI 推論需求爆發，隱私合規推動邊緣部署
- 分析：laya、laya-mlx、laya-coreml 系列專案同日登上 GitHub 趨勢榜，顯示開發者對無需雲端 API、在裝置端完成決策的解決方案需求強勁，這與企業資料隱私合規要求高度一致，台灣企業在個資法與 GDPR 合規壓力下，邊緣 AI 部署將成為未來 12 個月的重要趨勢，硬體廠商（尤其 Apple Silicon 生態相關）將間接受惠。
- 連結：https://www.google.com/url?q=https://github.com/NandhaKishorM/laya&source=gmail&ust=1790374326178000&sa=E

**3.**
- 主題：企業開源轉向加速，封閉 AI 工具整合能力不足成關鍵痛點
- 分析：研究顯示，花了兩年推動專有 AI 試點的企業，正因封閉工具無法與現有系統連結而回頭擁抱開源，這個趨勢利好台灣 Open Source 社群與系統整合商，但也對純商業 SaaS AI 廠商帶來競爭壓力，能提供「開源 + 企業支援服務」組合的廠商將具備差異化優勢。
