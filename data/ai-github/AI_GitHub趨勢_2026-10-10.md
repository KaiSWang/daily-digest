二、GitHub 熱門專案

**1.**

- 主題：addyosmani/agent-skills
- 功能：為 AI Agent 打造的生產級工程技能庫，包含效能優化、安全強化、無障礙設計、測試策略與可觀測性等模組。每個技能模組包含上下文、檢查清單、反模式與決策樹，可直接載入 AI Agent 使用。
- 成長幅度：累計 102,488 顆星、10,739 個 fork，被描述為 GitHub 史上成長最快的專案之一。
- 可應用領域發想：開發團隊可將這些技能模組整合到 CI/CD 管線中的 AI Agent，自動執行程式碼品質檢查與安全審計。

**2.**

- 主題：trycua/cua（Computer-Use Agent）
- 功能：跨平台電腦操作 Agent 基礎設施，以 Rust 撰寫。提供 macOS、Windows、Linux 統一 API，支援容器化隔離以實現水平擴展，內建標準化基準測試，使用 Apple Virtualization Framework、Windows Sandbox 與 Docker 進行虛擬化。
- 成長幅度：累計 28,617 顆星、2,034 個 fork。
- 可應用領域發想：適合需要大規模自動化桌面操作的企業，如軟體測試自動化、RPA 流程升級、以及 AI Agent 操作訓練資料的自動生成。
- 連結：https://www.google.com/url?q=https://github.com/trycua/cua&source=gmail&ust=1791672159028000&sa=E

**3.**

- 主題：manaflow-ai/cmux
- 功能：基於 Ghostty 終端機的 AI Agent 會話管理工具，以 Swift 撰寫，目前僅支援 macOS。提供垂直分頁側邊欄顯示各 Agent 狀態、桌面通知（支援 Claude Code、Codex、OpenCode、Gemini、Amp 等 Agent）、專案導向工作區可儲存與還原、以及可程式化 API 自動化工作區設定。
- 成長幅度：累計 27,731 顆星、2,458 個 fork，Linux 與 Windows 版本開發中。
- 可應用領域發想：適合同時運行多個 AI 編碼助手的開發者，統一管理並監控各 Agent 的任務進度，提升多 Agent 協作效率。
- 連結：https://www.google.com/url?q=https://github.com/manaflow-ai/cmux&source=gmail&ust=1791672159028000&sa=E

**4.**

- 主題：cloudflare/security-audit-skill
- 功能：Cloudflare 開源的自動化多階段安全審計框架，專為 AI Agent 設計。涵蓋依賴項分析（考慮漏洞函式庫的實際使用方式）、AI 驅動的程式碼模式分析（SQL 注入、XSS、硬編碼密鑰）、CORS/CSP/認證/限流等配置審查，並輸出機器可讀的 JSON 報告，適合整合至 CI/CD 管線做為品質閘門。

- 可應用領域發想：資安團隊可將此框架整合至現有 DevSecOps 流程，讓 AI Agent 在每次部署前自動執行安全掃描並產出結構化報告。
- 連結：https://www.google.com/url?q=https://github.com/cloudflare/security-audit-skill&source=gmail&ust=1791672159028000&sa=E

- 可應用領域發想：開發者應開始學習 MCP 規範並為自家服務建構 MCP Server，以確保產品能被各大 AI 平台的 Agent 直接調用。

**3.**

- 主題：Microsoft Copilot 導入用量計費模式（Copilot Credits）
- 功能：Microsoft 將 Copilot 分為固定月費（聊天及 Word/Excel/PowerPoint/Outlook/Teams 整合）與用量計費（Agentic 工作以 Copilot Credits 計費）兩層定價。新增 Cowork（委派工作）、Code（應用開發）與 Autopilot（背景 Agent）三項功能。管理員可在管理中心設定用量上限。
