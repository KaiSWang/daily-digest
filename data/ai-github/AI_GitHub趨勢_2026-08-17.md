- 成長幅度：2026 年持續位列 GitHub AI 類 trending 前五名，社群貢獻者數量年增逾 200%。

四、趨勢觀察（2 則）

**1.**

- 主題：AI 代理人（AI Agents）成為開源生態主軸
- 分析：2026 年 GitHub 上 AI 代理框架、技能庫（skills）、computer-use 工具的成長速度遠超基礎 LLM 研究，反映業界已從「如何讓模型更聰明」轉向「如何讓模型自主完成任務」。這一趨勢推動整個軟體開發工具鏈向代理優先（agent-first）的方向重組，也讓工作流程自動化、工具整合、記憶系統成為開發者關注的新核心課題。
- 連結：https://www.google.com/url?q=https://ossinsight.io/trending/ai&source=gmail&ust=1787091211135000&sa=E

**2.**

- 主題：LLM 微調民主化加速垂直應用落地
- 分析：Axolotl、TRL 等低門檻微調框架的普及，配合 AI 伺服器硬體成本持續下降，使中小型企業已能負擔訓練自有專屬 LLM 的成本。此趨勢將加速 AI 在醫療、法律、金融等高度專業化領域的落地，資料主權也因此成為企業選擇開源自訓模型與外部 API 的關鍵決策因素，台灣具備語料累積優勢的垂直領域業者可率先受益。
