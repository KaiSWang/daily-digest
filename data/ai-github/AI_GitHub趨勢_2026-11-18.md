二、GitHub 熱門專案（至少 5 個）

**1.**
- 主題：ChromeDevTools/chrome-devtools-mcp
- 功能：將 Chrome DevTools 完整功能以 MCP（Model Context Protocol）標準暴露給 AI 編程代理，讓 Claude Code、Cursor 等工具可直接操控瀏覽器 DOM 檢視、網路請求攔截與效能分析，實現真正的 AI 驅動前端開發閉環
- 成長幅度：56,405 顆星，4,777 個 Fork，近一週新增 3,200+ 顆星
- 可應用領域發想：前端自動化測試、AI 驅動的 UI 迴歸分析、無障礙稽核自動化流程，可大幅減少 QA 工程師的手動測試時間

**2.**

- 成長幅度：11 月 16 日 24 小時內新增 1,220 顆星，連續 4 天位居 GitHub Trending 榜首
- 可應用領域發想：前端工程師可以此作為 2027 年 Web 技術規劃的參考基準；AI 編程工具廠商可將此指南作為 Web 任務的 RAG 知識庫，提升代理在 Web 開發任務上的準確性
- 連結：https://www.google.com/url?q=https://github.com/GoogleChrome/modern-web-guidance-src&source=gmail&ust=1795040144993000&sa=E

**3.**

- 連結：https://www.google.com/url?q=https://github.com/ag-ui-protocol/ag-ui&source=gmail&ust=1795040144993000&sa=E
