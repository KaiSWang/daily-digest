一、AI 產業重點新聞

**1.**

- 主題：OpenAI 下一代模型 Astra 解決 10 個長年未解數學難題
- 功能：OpenAI 宣布其尚未公開發佈的 Astra 模型，成功解決了 10 個橫跨數學與理論電腦科學的開放問題，每個問題至少懸而未決超過十年。涵蓋高維幾何、編碼理論、群論、量子複雜度、格密碼學、算子代數與極值組合學等領域。其中包括構造出首個非 sofic 群（解決 Gromov 1999 年提出的問題）、反證 Connes 剛性猜想、證明 Ehrhart 體積猜想，以及解決三個 Erdos 目錄中的問題。
- 成長幅度：所有 10 個解答的總計算成本約 2,000 美元（以 GPT-5.6 Sol API 費率計算），並在 GitHub 上公開了形式化 Lean 證明
- 可應用領域發想：AI 在純數學與理論研究中的應用正從輔助工具升級為獨立研究者角色，未來可能加速密碼學、量子運算、最佳化等領域的基礎突破
