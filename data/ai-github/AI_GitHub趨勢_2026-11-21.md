一、AI 產業重點新聞（4 則）

**1.**
- 主題：Anthropic 以 813 億美元完成史上最大規模 AI IPO
- 功能：Anthropic 於 11 月 19 日正式在美股掛牌（代號 ANT），以每股 83 美元定價，募資總額 813 億美元超越 SpaceX 六月 IPO 的歷史紀錄。首日開盤大漲 34%，但受 AI 拋售潮影響，次日跌 8.5% 至 88.91 美元收盤，僅略高於 IPO 定價，台積電董事會已核准投資 Anthropic 上限 5 億美元。
- 成長幅度：市值約 8,600 億美元，IPO 首日上漲約 17%，為 AI 新創史上最高首發市值
- 可應用領域發想：Anthropic 上市後資金充沛，Claude 模型迭代速度可望加快，台灣開發者可預期 Claude API 功能更豐富；同時 Anthropic 上市也為台灣 AI 新創提供估值參考基準

- 成長幅度：Google AI 服務用戶持續成長，Gemini 系列 2026 年已密集迭代多個版本，更新週期大幅壓縮
- 可應用領域發想：台灣企業可藉由 Google Workspace 整合 Gemini 4 Neon 進行文件摘要、程式碼生成與客服自動化，特別適合中小企業 AI 導入的第一步；開發者可評估 Gemini API 與 Claude API 在推論成本與功能上的差異

- 連結：https://www.google.com/url?q=https://github.com/ChromeDevTools/chrome-devtools-mcp&source=gmail&ust=1795385687951000&sa=E

**2.**
- 主題：alibaba/open-code-review

- 連結：https://www.google.com/url?q=https://github.com/alibaba/open-code-review&source=gmail&ust=1795385687951000&sa=E
