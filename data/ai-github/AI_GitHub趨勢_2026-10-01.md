- 主題：NVIDIA 發布 OpenShell 開源 AI Agent 安全平台
- 功能：OpenShell 是一套 Apache 2.0 授權的沙盒化 Runtime，為 AI Agent 定義並強制執行權限政策，控制 Agent 可存取的檔案、網路、工具與憑證。搭配 Sentry 硬體監控層（運行於 BlueField DPU），可在毫秒內隔離越權 Agent，形成軟硬體雙層安全架構。
- 成長幅度：發布首週即獲超過 100 家企業夥伴加入，Anthropic 與 SpaceXAI 均已宣布合作
